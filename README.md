# 🎓 Student Performance Predictor

A web app that predicts a student's Performance Index from study habits, built with Linear Regression.

🔗 **Live app:** https://student-performance-app-ml-model.streamlit.app/

## Inputs
Hours studied, previous scores, extracurricular activities, sleep hours, sample papers practiced.

## Model results
- Algorithm: Linear Regression (scikit-learn)
- R² score:  0.98
- Dataset: Student_Performance.csv

## Tech stack
Python, pandas,numpy, scikit-learn, Streamlit

## Files
- `app.py`: Streamlit interface
- `model.pkl`: trained model
- `Linear Regression ML.ipynb`: training notebook
